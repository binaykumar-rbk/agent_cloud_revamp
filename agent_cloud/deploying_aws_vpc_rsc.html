      • Connect your agents

        A connection links Agent Cloud to a source of agent activity, such as an enterprise AI platform, a gateway that your custom agents use, or the endpoint detection binary on employee devices.

      • Discover and observe

        Agent Cloud builds an inventory of the agents, tools, identities, models, and MCP servers in your environment, and records what each agent does, session by session.

      • Govern and control

        Agent Cloud policies are the governance rules that define the acceptable behavior for your AI agents. Use them to detect risky activity and, on connections that support it, stop it.

      • Rewind agent actions

        Agent Rewind undoes the changes that an agent action made to your data by restoring the affected objects from Rubrik backups, without rolling back the entire workload. You can start a rewind from the Sessions page, or from any page that displays the action or alert detail tray. Rewind requires a complete Rubrik snapshot taken within seven days before the action.

Deploying AWS VPC on Agent Cloud

Deploy AWS VPC infrastructure in your AWS account to enable Agent Cloud. Rubrik Support completes the final configuration steps.

Before you begin

This is the first step of the AWS VPC deployment. Before you start, review Best practices and request any AWS service quota increases that you need. Rubrik Support completes the final provisioning steps after you send the CustomerEnvironmentRoleArn value.

Procedure

  1. Connect to the playground on your RSC instance.
    Navigate to https://your_tenant_name.my.rubrik.com/playground.
  2. Use the mutation command to enable VPC support.
    Enter this in the edit field:
    mutation createVpcTenant($input: AirCreateVpcTenantInput!) {
  airCreateVpcTenant(input: $input) {
    id
    name
    shortcode
  }
}
  3. Enter this text in the Variables field: 
    {
  "input": {}
}
  4. Click the red button to run the query.
    The text in the results field starts with this structure:
    {
  "data": {
    "airCreateVpcTenant": null
  },
.
.
.
  5. Request your PredibaseEnvironmentID from your Rubrik representative.
  6. Sign in to your dedicated AWS Management Console.
    Verify that you are operating in the AWS region that you intend to use for the VPC deployment.
  7. Navigate to CloudFormation.
  8. Click Create stack > With new resources (standard).
  9. From Specify the template, select Amazon S3 URL.
  10. Paste the CloudFormation URL in the text field.
    The CloudFormation URL is https://s3-us-west-2.amazonaws.com/predibase-public-us-west-2/infrastructure/rbrk-dataplane-preprovision.json.
  11. Click Next.
  12. Specify the stack details.
    Your Rubrik contact will provide you with the preconfigured values for the parameters on this page. Using incorrect values causes the deployment to fail.
  13. Click Next.
  14. Select I acknowledge that AWS CloudFormation might create IAM resources with custom names.
  15. Click Create Stack.
    The AWS Management Console creates the stack. This typically takes between four and five minutes to complete. When the stack is created, the AWS Management Console displays a status of CREATE_COMPLETE.
  16. In the AWS Management Console, select the newly created stack and navigate to the Outputs tab.
  17. Copy the CustomerEnvironmentRoleArn value.
  18. Send the CustomerEnvironmentRoleArn value to your Rubrik contact.
    You can send the value using your shared Slack channel or by email.

Results

You have deployed AWS VPC on Agent Cloud by provisioning the VPC infrastructure in your AWS account.
When Rubrik Support receives CustomerEnvironmentRoleArn, they complete the final provisioning steps to connect your AWS VPC infrastructure to RSC. These steps include:
  • Provisioning the infrastructure. The automated provisioning process takes approximately 20 to 30 minutes.
  • Verifying the infrastructure. Rubrik Support validates that the infrastructure provisioned successfully and informs you when it is ready to use. This can take up to 48 hours.
  • Completing the deployment. Rubrik Support notifies you after the environment is connected and Agent Cloud is enabled and visible on RSC.
