ChatGPT Enterprise deployed in Agent Cloud

Agent Cloud polls OpenAI's Compliance API every 10 minutes to discover custom GPTs and ingest conversations and tool calls from a ChatGPT Enterprise workspace.

Deploying ChatGPT Enterprise on Agent Cloud provides administrators visibility into generative-AI usage across the ChatGPT Enterprise workspace. When an administrator connects a workspace, Agent Cloud discovers active custom-generative, pre-trained transformers (GPTs) and ingests conversation and tool-call data so administrators can identify unauthorized activity or policy violations.

This table lists what Agent Cloud supports for ChatGPT Enterprise.
CapabilitySupport
DiscoveryAgents, tools, sessions, identities
Session activityUser prompts, agent responses, tool calls, tool responses
ViolationsYes
MonitorYes
BlockNot supported
AskNot supported

For all connections, see the Agent Cloud support matrix.

How the integration works

When an administrator creates a connection, Agent Cloud polls OpenAI's Compliance API for workspace activity on a fixed schedule. Four parameters govern the data flow:

  • Admin API key: Agent Cloud authenticates to the Compliance API with an Admin API key that an administrator creates in the ChatGPT Enterprise admin console. OpenAI provisions Compliance API access for each key manually, on request.
  • Workspace scope: One connection ingests a single ChatGPT Enterprise workspace. To monitor multiple workspaces, an administrator creates a separate connection for each workspace.
  • Polling interval: Agent Cloud checks the Compliance API for new activity every 10 minutes. The interval is fixed and administrators cannot change it.
  • Initial lookback: The first check after an administrator creates a connection looks back 4 hours. Agent Cloud does not ingest activity that predates the connection by more than 4 hours.

Requirements

You need a ChatGPT Enterprise plan, the workspace Owner role, and Compliance API access with the read scope for an Admin API key. See ChatGPT Enterprise coverage and requirements for Agent Cloud.

Limitations

  • Near real time, not real time: activity appears about 10 minutes after it happens, and the polling interval cannot be changed. Agent Cloud cannot block actions through this connection. Block policies on this connection behave like monitor policies. See How blocking works.
  • One connection per workspace. To monitor several workspaces, create a connection for each one.
  • The first poll looks back 4 hours. Older activity is not ingested, including when you delete and re-add a connection, for example to rotate the key.
  • Edited or regenerated messages appear as a single linear conversation, because the Compliance API does not expose branches.
  • Only text content is ingested. Image generation, voice mode, file uploads, and code interpreter output are not.
  • Sessions are attributed to users by their ChatGPT Enterprise email, and are not linked to other identity platforms.
  • Only the custom GPTs that the Compliance API exposes appear in the inventory.
