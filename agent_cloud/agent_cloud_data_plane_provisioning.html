      • Get started with Agent Cloud

        To start using Agent Cloud, confirm the prerequisites, deploy a data plane, connect your agents, verify the setup, and then add policies.

      • Choose your data plane

        The Agent Cloud data plane runs as a SaaS deployment that Rubrik operates, or in your own AWS VPC or Azure VNet. Choose where it runs before you connect your AI providers and agents.

        • Region support for Agent Cloud

          Agent Cloud supports regions across SaaS, AWS, and Azure deployments.

        • Provision SaaS infrastructure

          The SaaS deployment of Agent Cloud uses a Rubrik-managed data plane that RSC provisions automatically when you onboard your AI provider connections. Traffic between your SaaS-based AI agents and Agent Cloud is brokered through this dedicated Rubrik-managed infrastructure.

        • AWS VPC deployment

          Deploying AWS VPC in Agent Cloud involves provisioning the necessary infrastructure directly within your AWS account to establish a dedicated data plane.

        • Azure VNet deployment

          In an Azure VNet deployment, the Agent Cloud data plane runs in your own Azure subscription, so prompts, responses, and other agent content stay inside your cloud boundary.

      • Connect your AI agents

        A connection links Agent Cloud to a source of agent activity, such as an enterprise AI platform, a gateway that your custom agents use, or the endpoint detection binary on employee devices.

      • Discover and observe

        Agent Cloud builds an inventory of the agents, tools, identities, models, and MCP servers in your environment, and records what each agent does, session by session.

      • Manage Agent Cloud policies

        Agent Cloud policies are the governance rules that define the acceptable behavior for your AI agents. Use them to detect risky activity and, on connections that support it, stop it.

      • Rewind AI agent changes with Agent Cloud

        Agent Rewind undoes the changes that an agent action made to your data by restoring the affected objects from Rubrik backups, without rolling back the entire workload. Rewind requires a complete Rubrik snapshot taken within seven days before the action.

      • Administer Agent Cloud

        Control who can see and manage Agent Cloud, review platform and user activity, understand who is responsible for each part of a deployment, and follow best practices for rollout and for building agents that are easier to govern.

Choose your data plane

The Agent Cloud data plane runs as a SaaS deployment that Rubrik operates, or in your own AWS VPC or Azure VNet. Choose where it runs before you connect your AI providers and agents.

The data plane reads and processes agent activity, such as prompts, responses, and tool calls, and evaluates your policies against it. It sends the resulting metadata and policy results to the Agent Cloud control plane, which builds the inventory, dashboards, and alerts. Where the data plane runs determines where agent content is processed and who pays for that processing.

Important:
You can run the Agent Cloud data plane in only one location at a time. If you require multiple data planes, contact Rubrik Support.

Compare deployment models

This table compares the SaaS, AWS VPC, and Azure VNet data plane deployment models.
Attribute SaaS AWS VPC Azure VNet
Who operates the data plane Rubrik Rubrik operates the software; the infrastructure runs in your AWS account. Rubrik operates the software; the infrastructure runs in your Azure subscription.
Where agent content is processed In a dedicated tenant in RSC In your AWS VPC. Content is stored in a private Amazon S3 bucket in your account. In your Azure VNet. Content is stored in a private Azure Blob Storage container in your subscription.
Your responsibilities Your agents, provider accounts, and the credentials that you give Agent Cloud for each connection Everything in the SaaS column, plus the security, access controls, and service quotas of the AWS account that hosts the data plane, and keeping the deployed resources intact Everything in the SaaS column, plus the security, access controls, and service quotas of the Azure subscription that hosts the data plane, and keeping the deployed resources intact
Infrastructure cost Paid by Rubrik Billed to your AWS account Billed to your Azure subscription
Private connectivity Not applicable. Agents reach the data plane over the internet. Optional, using AWS PrivateLink Optional, using Azure Private Link
Setup Automatic when Agent Cloud is enabled You run a Rubrik-provided CloudFormation template, and Rubrik Support completes the deployment. You run a Rubrik-provided Azure template, and Rubrik Support completes the deployment.

Choose a deployment model

  • Choose SaaS if your agents run on vendor-managed platforms, if you do not require prompts and responses to stay inside your own cloud boundary, or if you want the fastest path to onboarding.
  • Choose AWS VPC or Azure VNet if agent content must stay in your own cloud account, or if your custom agents run in that cloud and you want lower latency between the agents and the data plane.

In every deployment model, the control plane receives only enriched metadata and policy evaluation results. This metadata is joined with existing data to show what AI agents are capable of doing, what they are actually doing, and what they are permitted to do.
