      • Introduction to Agent Cloud
      • Get started with Agent Cloud

        To start using Agent Cloud, confirm the prerequisites, deploy a data plane, connect your agents, verify the setup, and then add policies.

      • Choose your data plane

        The Agent Cloud data plane runs as a SaaS deployment that Rubrik operates, or in your own AWS VPC or Azure VNet. Choose where it runs before you connect your AI providers and agents.

      • Connect your AI agents

        A connection links Agent Cloud to a source of agent activity, such as an enterprise AI platform, a gateway that your custom agents use, or the endpoint detection binary on employee devices.

      • Discover and observe

        Agent Cloud builds an inventory of the agents, tools, identities, models, and MCP servers in your environment, and records what each agent does, session by session.

      • Manage Agent Cloud policies

        Agent Cloud policies are the governance rules that define the acceptable behavior for your AI agents. Use them to detect risky activity and, on connections that support it, stop it.

      • Rewind AI agent changes with Agent Cloud

        Agent Rewind undoes the changes that an agent action made to your data by restoring the affected objects from Rubrik backups, without rolling back the entire workload. Rewind requires a complete Rubrik snapshot taken within seven days before the action.

Editing roles for session viewing access

Edit a custom role to add the View Session Timelines and Summaries permission, granting users access to view session data in Agent Cloud.

About this task

Session content can contain sensitive data, and no built-in role includes the View Session Timelines and Summaries privilege. Grant it only to users who need to investigate agent sessions. Selecting it also includes the base view of the Agent Cloud application. For what each privilege grants, see Access control for Agent Cloud.

Procedure

  1. Log in to RSC.
  2. Click the menu icon and select Settings.
  3. Click Users & Access > Roles.
  4. For the role you want to edit, select and then click Edit.
    RSC displays the Edit Role wizard.
  5. On Rubrik Application Privileges, click Configure.
    RSC displays the Edit an Existing Role wizard.
  6. Locate Rubrik Agent Cloud and select the permissions to assign.
    This table describes the three RBAC permissions included with Agent Cloud.
    Permission Category Permissions provided
    View Alerts, Insights, Violations, Policies, Connections, and Inventories View View alerts, insights (metadata only), violations, policies, connections, and inventories.
    View Session Timelines and Summaries View View session timelines, session messages, extracted entities, session models, and evidence content within insights, alerts, or any investigation.
    Manage Policies and Connections Manage Create, edit, archive, and delete policies. Create, update, and delete connections. Manage policy exceptions and tool statuses.
  7. Click Done.
    RSC updates the role and refreshes the Rubrik Application Privileges page, listing the privileges added for this role.
  8. Click Next.
  9. In Role Details, enter the role information.
    FieldDescription
    Role Name Name for the role
    Description Optional description of the role
    Synchronize Role to CDM Clusters When enabled, this role is synchronized to Rubrik clusters that are running Rubrik CDM versions 9.3 or later for offline recovery.
  10. Click Save.

Results

You have edited an existing role to include the View Session Timelines and Summaries permission.

What to do next

Have the affected user navigate to Runtime > Sessions to confirm the Sessions tab is visible.
