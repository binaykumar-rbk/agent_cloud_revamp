              Agent Cloud captures Claude Code sessions from the device and enforces policies on Claude Code prompts, tool calls, and tool results in real time, through hooks in Claude Code's managed settings.

            • GitHub Copilot

              Agent Cloud captures GitHub Copilot sessions from the device and, on macOS and Linux, blocks Copilot tool calls in real time through hooks that the endpoint detection binary installs.

            • MCP gateway (Early access)

              An MCP gateway is a single governed endpoint between your AI agents and the MCP servers that they use. It authenticates the person behind each agent against your identity provider and forwards only the tool calls that your MCP access policies allow.

      • Discover and observe

        Agent Cloud builds an inventory of the agents, tools, identities, models, and MCP servers in your environment, and records what each agent does, session by session.

      • Govern and control

        Agent Cloud policies are the governance rules that define the acceptable behavior for your AI agents. Use them to detect risky activity and, on connections that support it, stop it.

      • Rewind agent actions

        Agent Rewind undoes the changes that an agent action made to your data by restoring the affected objects from Rubrik backups, without rolling back the entire workload. You can start a rewind from the Sessions page, or from any page that displays the action or alert detail tray. Rewind requires a complete Rubrik snapshot taken within seven days before the action.

Codex (Early access)

Agent Cloud captures OpenAI Codex sessions from the device and enforces policies on Codex prompts, tool calls, and tool results in real time, through hooks in Codex's managed configuration.

Note:
Codex support is an early access feature. For how to opt in, see Early access features.

How Agent Cloud integrates with Codex

  • Discovery: reports that Codex is installed, from either the Codex CLI or the Codex desktop app. To avoid reading credentials, Agent Cloud reports only that Codex is present, not its configuration.
  • Session capture: reads Codex's session transcripts from the device and uploads new activity on each run. Sessions include prompts, responses, tool calls with their arguments and results, the model used, and token usage.
  • Real-time enforcement: installs hooks in Codex's system-wide managed configuration. Before Codex sends a prompt or runs a tool, it sends the item to Agent Cloud, which allows or blocks it. After a tool runs, its result is checked and can be redacted.

Codex form factors

Coverage applies to Codex wherever it runs on the user's computer and stores its sessions in its local session directory, which includes the Codex CLI. Codex tasks that run in OpenAI's cloud do not run on the device and are not covered.

Deploying

Deploy the endpoint detection binary with your MDM solution, and enable the Codex hooks. In Jamf Pro, set parameter $8 to true. When you run the binary yourself, pass -install-codex-managed-config. Session capture does not need the hooks. For details, see Endpoint detection requirements.

Limitations

  • Codex has no approval prompt that Agent Cloud can use, so Ask policies fall back to Monitor or Block for Codex.
  • Blocking fails open: if Agent Cloud does not respond, Codex runs the action. For details, see Blocking limitations and fail-open behavior.
