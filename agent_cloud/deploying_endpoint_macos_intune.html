Deploying endpoint detection on macOS using Microsoft Intune

Use Microsoft Intune to deploy the Rubrik endpoint detection binary to your fleet of macOS devices so Agent Cloud can monitor Claude Code activity.

Before you begin

Confirm the following:
  • You are a Microsoft Intune administrator with permission to add shell scripts and Settings catalog configuration profiles.
  • You have the macOS version of the Rubrik endpoint detection binary, the endpoint URL, and the API key for the endpoint detection connection in Agent Cloud.
Note:
Microsoft Intune deployment is supported on Windows and macOS. For Linux, use an existing configuration management tool.

About this task

Intune does not pass the device name or the primary user into scripts as positional parameters. Either omit -hostname and -username and let the binary auto-detect them, or resolve them at runtime in the wrapper, as shown below.

Deliver the API key as a machine-scope environment variable through a Settings catalog configuration profile so the value stays out of script bodies.

The examples below use:

  • <BINARY_URL> as the binary download URL
  • <YOUR_API_KEY> for the API key
  • <YOUR_ENDPOINT_URL> for the endpoint URL.

Procedure

  1. Select Devices > macOS > Shell scripts.
  2. Upload the wrapper as root.
    The wrapper downloads racdiscovery-darwin-universal, sets the API key, resolves the hostname and the console user, and runs the Rubrik endpoint detection binary.
    #!/bin/bash
set -euo pipefail
BIN=/tmp/racdiscovery-darwin-universal
HOSTNAME=$(scutil --get ComputerName)
USERNAME=$(stat -f%Su /dev/console)
curl -sSfL "<BINARY_URL>" -o "$BIN"
chmod 755 "$BIN"
API_KEY="<YOUR_API_KEY>" "$BIN" \
  -endpoint "<YOUR_ENDPOINT_URL>" \
  -hostname "$HOSTNAME" \
  -username "$USERNAME" \
  -install-claude-code-managed-settings
  3. Set the script to run as root, with a frequency of 60 minutes.
    The 60-minute frequency comfortably exceeds the 15-minute minimum documented by Intune .
  4. Optional: For a sub-hourly schedule on a pilot fleet, deploy a LaunchDaemon .plist through a Custom Configuration Profile (.mobileconfig) instead of the shell script.

Results

The Rubrik endpoint detection binary is deployed to your fleet of macOS devices via Microsoft Intune. The fleet reports Claude Code activity to Agent Cloud on the configured schedule, and Claude Code on each device enforces the managed settings that Agent Cloud distributes.
