    Detect risky actions caused on your data by autonomous AI agents, and rewind the actions to repair changes to the data and configurations without downtime.

    • Agent Cloud with RSC

      Agent Cloud with RSC provides a comprehensive solution for discovering AI agents in your environment, understanding which tools they have access to, detecting risky actions they perform on your data and configurations, and rewinding unauthorized changes without downtime.

      • Introduction to Agent Cloud
      • Get started with Agent Cloud

        To start using Agent Cloud, confirm the prerequisites, deploy a data plane, connect your agents, verify the setup, and then add policies.

      • Choose your data plane

        The Agent Cloud data plane runs as a SaaS deployment that Rubrik operates, or in your own AWS VPC or Azure VNet. Choose where it runs before you connect your AI providers and agents.

      • Connect your AI agents

        A connection links Agent Cloud to a source of agent activity, such as an enterprise AI platform, a gateway that your custom agents use, or the endpoint detection binary on employee devices.

      • Discover and observe

        Agent Cloud builds an inventory of the agents, tools, identities, models, and MCP servers in your environment, and records what each agent does, session by session.

        • AI inventory

          The inventory lists everything that Agent Cloud has discovered across your connections: agents, tools, identities, models, and MCP servers.

        • Sessions and actions

          Agent Cloud records what your agents do as sessions, each with a timeline of prompts, responses, and tool calls, and as actions, the individual tool calls within them.

        • Dashboard and Explorer

          The Dashboard summarizes your agent environment and its open issues. The Explorer maps which agents can access which tools and applications.

          • Viewing the Explorer

            View a map of agent-to-tool relationships in Agent Cloud, showing which agents have access to which tools and to which applications they belong.

        • Connections

          The Connections page displays all the connections configured on Agent Cloud. These include SaaS platform integrations, such as Microsoft Copilot Studio or AWS Bedrock, MDM connections for endpoint detection, and AI gateways (Rubrik-managed or plug-ins to third-party gateways such as LiteLLM).

      • Manage Agent Cloud policies

        Agent Cloud policies are the governance rules that define the acceptable behavior for your AI agents. Use them to detect risky activity and, on connections that support it, stop it.

      • Rewind AI agent changes with Agent Cloud

        Agent Rewind undoes the changes that an agent action made to your data by restoring the affected objects from Rubrik backups, without rolling back the entire workload. Rewind requires a complete Rubrik snapshot taken within seven days before the action.

      • Administer Agent Cloud

        Control who can see and manage Agent Cloud, review platform and user activity, understand who is responsible for each part of a deployment, and follow best practices for rollout and for building agents that are easier to govern.

Dashboard and Explorer

The Dashboard summarizes your agent environment and its open issues. The Explorer maps which agents can access which tools and applications.

Dashboard

To open the Dashboard, click Dashboard. It shows overall statistics, an Agent Environment summary, Active Alerts and Active Violations by severity, Highest-Risk Agents, Top Violated Policies, and Recent Insights. An agent can be high risk without having any violations. For more information about insights, see Viewing insights.

The following table describes the AI agent actions Agent Cloud monitors.
Action Description
Agents Discovered Number of AI agents discovered in the customer environment.
High-Risk Agents Number of AI agents that pose a high- risk to customer data.
Tools Discovered Number of tools Agent Cloud found running on the workload. Tools are specific functions or APIs that AI agents use to perform an action.
Active Violations Number of active violations the Agent Cloud has found.
Active Alerts Number of active alerts Agent Cloud has detected.
Attention:
Clicking any of the overview headings opens the corresponding page. For example, clicking the High-Risk Agents heading opens the Agent Inventory page.
This table describes the columns in the Highest-Risk Agents table. This table includes information about high risk agents, not agents that are causing violations. There can be high-risk agents that have no violations.
Heading Description
Agent Name of the high-risk AI agent.
Agent Risk Level of risk for this high-risk AI agent.
Active Violations Number of active violations the high-risk AI agent is causing.
Active Alerts Number of active alerts Agent Cloud has detected.
The following table describes the columns in the Active Violations table.
Heading Description
Violation Summary Brief description of the violation.
Entities Affected List of the entities affected by the violation.
Detected On Date and time Agent Cloud detected the violation.

Explorer

The Explorer page in Agent Cloud provides a visual map of which AI agents have access to which tools, helping you understand the relationships between agents, tools, and applications in your environment.

The following table describes the details for the Explorer overview.
Heading Description
Active Agents Number of agents that performed actions during the selected time range.
Agents Tracked Number of AI agents running on the system that Agent Cloud is tracking.
The following table describes the filters for the Explorer page.
Heading Description
Time Range The AI agent filters based on a time range. You can select the custom option to specify a specific time range.
Agent Risk The level of risk the action performed by the AI agent poses for your data or configuration.
Agent Name of the AI agent that performed the reported action.
Application Application issuing the AI agent.
Status Status of the tool issued by the AI agent. It can be any one of the following:
  • Block: Prevent the action from occurring.
  • Monitor: Monitor the action.

You can use the View by list to switch between showing agent-to-tool relationships and showing the applications running those AI agents.

The Explorer includes a timeline that tracks the total number of agent or application actions. The period the timeline covers is determined by the time range to which you set the Explorer. Hovering over the timeline shows a tooltip with the date, the number of high-impact actions that triggered violations or alerts, and the total number of agent actions recorded at that point in time.

Hovering over the timeline also reveals a dot that indicates the date, the number of high-impact actions, and the number of AI actions, regardless of the number of rewinds.
