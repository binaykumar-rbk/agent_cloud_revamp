      • Introduction to Agent Cloud
      • Get started with Agent Cloud

        To start using Agent Cloud, confirm the prerequisites, deploy a data plane, connect your agents, verify the setup, and then add policies.

      • Choose your data plane

        The Agent Cloud data plane runs as a SaaS deployment that Rubrik operates, or in your own AWS VPC or Azure VNet. Choose where it runs before you connect your AI providers and agents.

      • Connect your AI agents

        A connection links Agent Cloud to a source of agent activity, such as an enterprise AI platform, a gateway that your custom agents use, or the endpoint detection binary on employee devices.

      • Discover and observe

        Agent Cloud builds an inventory of the agents, tools, identities, models, and MCP servers in your environment, and records what each agent does, session by session.

      • Manage Agent Cloud policies

        Agent Cloud policies are the governance rules that define the acceptable behavior for your AI agents. Use them to detect risky activity and, on connections that support it, stop it.

        • How policies work

          A policy is a named rule with a severity that Agent Cloud evaluates against your agents, tools, and sessions. When agent activity breaks a policy, Agent Cloud records a violation or an alert and, depending on the policy's enforcement mode, can stop the action.

        • Plan your policy rollout

          Introduce policies in Monitor mode, review the alerts they produce, and move a policy to Block only after it behaves as you expect and only on connections that support blocking.

        • Enforcement modes

          A policy's enforcement mode determines what happens when agent activity breaks it: Monitor records an alert, and Block stops the action before it runs.

        • How blocking works

          A Block policy lets Agent Cloud stop an agent action before it takes effect, inline with the agent's own execution, instead of only flagging it afterward.

        • Agent Cloud system policies

          Agent Cloud includes multiple system policies. These policies are not enabled by default. You can enable them from the Policies page.

        • Agent Cloud policy packs

          Agent Cloud policy packs are curated collections of system policies you can add to your Agent Cloud account to enable a focused set of controls for a specific risk area, compliance framework, or industry.

        • Custom policies

          A custom policy is a rule that you write in plain English. The Semantic AI Governance Engine (SAGE) turns it into a policy that it judges against agent activity by intent, not by matching keywords.

        • Viewing the Agent Cloud policies

          View the list of policies that govern Agent Cloud.

        • Enabling or disabling Agent Cloud policies

          Enable or disable policies to control which agent actions Agent Cloud monitors and enforces.

        • Alerts and violations

          Alerts and violations are the findings that your policies produce. An alert is a specific action or message that broke a policy. A violation is a standing configuration that breaks one.

        • Viewing insights

          View the Insights page to review security recommendations and posture improvements identified by Agent Cloud.

      • Rewind AI agent changes with Agent Cloud

        Agent Rewind undoes the changes that an agent action made to your data by restoring the affected objects from Rubrik backups, without rolling back the entire workload. Rewind requires a complete Rubrik snapshot taken within seven days before the action.

      • Administer Agent Cloud

        Control who can see and manage Agent Cloud, review platform and user activity, understand who is responsible for each part of a deployment, and follow best practices for rollout and for building agents that are easier to govern.

Manage Agent Cloud policies

Agent Cloud policies are the governance rules that define the acceptable behavior for your AI agents. Use them to detect risky activity and, on connections that support it, stop it.

If an AI agent performs an action that breaks a policy, Agent Cloud records an alert or a violation. Policies generally focus on actions that violate security, data privacy, and ethics requirements, and on keeping AI agents from altering important data. The lifecycle is: understand how policies work, plan your rollout, choose an enforcement mode, add system policies or policy packs, add custom policies for your own requirements, and triage what the policies find.

Important:
Blocking fails open: if Agent Cloud cannot reach a decision in time, the action proceeds. Most connections cannot block at all. Check Blocking support by connection before you choose Block. Ask is available on some accounts; contact your Rubrik account team.

System policies vs custom policies

This table compares system policies and custom policies.
Aspect System policies Custom policies
Provided by Rubrik. You cannot delete them. You, written in natural language.
Default state Not enabled by default. You enable them individually or add them in groups with policy packs. Active when you save them. New custom policies start in Monitor.
Enforcement Monitor or Block. Some can only Monitor. Monitor or Block.
Use for Common security, compliance, and operational risks. Requirements specific to your organization.

Where to start

  1. Read How policies work to learn the policy model.
  2. Plan the rollout with Plan your policy rollout. Start in Monitor.
  3. Enable Agent Cloud system policies or add a Agent Cloud policy packs.
  4. Add Custom policies for behavior specific to your organization.
  5. Triage Alerts and violations and Viewing insights on a schedule.
