Installing the endpoint detection binary on Linux

Install the Rubrik endpoint detection binary on a Linux device and schedule it to run every five minutes so Agent Cloud can monitor Claude Code activity and enforce policies.

Before you begin

In addition to the requirements described in Endpoint detection requirements, confirm that you have:
  • Claude Code installed on the device. To install Claude Code, see Claude Code.
  • Your sudo password for the one-time installation.

Review the Additional requirements for manual installation requirements before you start. To get the endpoint URL and API key, create the connection. For more information, see Connecting Mobile Device Management.

About this task

The examples that follow use:

  • <path-to-binary> as a placeholder for that absolute path
  • <YOUR_API_KEY> for the API key
  • <YOUR_ENDPOINT_URL> for the endpoint URL.

Procedure

  1. Make the Rubrik endpoint detection binary executable. 
    chmod +x <path-to-binary>
  2. Run the Rubrik endpoint detection binary with sudo to install the Claude Code managed settings. 
    sudo env API_KEY="<YOUR_API_KEY>" <path-to-binary> \
  -endpoint <YOUR_ENDPOINT_URL> \
  -install-claude-code-managed-settings
  3. Optional: If the cron service is not already running, start it. 
    sudo service cron start
  4. Schedule the Rubrik endpoint detection binary to run every five minutes by adding a cron entry. 
    (crontab -l 2>/dev/null; echo "*/5 * * * * API_KEY=<YOUR_API_KEY> <path-to-binary>
-endpoint <YOUR_ENDPOINT_URL> -install-claude-code-managed-settings >>
~/endpointdetection.log 2>&1") | crontab -
  5. Restart Claude Code. If you use the Claude Code extension, restart Visual Studio Code as well.
    Claude Code reads the newly installed managed settings on startup.

Results

The Rubrik endpoint detection binary is installed on the Linux device and scheduled to run every five minutes. Agent Cloud monitors Claude Code activity and enforces policies on the device.
