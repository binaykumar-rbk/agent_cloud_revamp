Determining Domain Restricted Sharing policy enforcement

Determine whether your organization enforces a Domain Restricted Sharing policy, and add an exception for the Rubrik service account or the Rubrik organization domain before connecting Google Cloud Gemini Enterprise to Agent Cloud.

Procedure

  1. Log in to the Google Cloud CLI.
  2. Identify the Domain Restricted Sharing policy status.
    You can issue this command in the Google Cloud CLI to determine whether your organization includes an active Domain Restricted Sharing policy.
    gcloud org-policies describe iam.allowedPolicyMemberDomains \
  --organization=<YOUR_ORG_ID>

    Where YOUR_ORG_ID is the ID for your organization.

  3. Update the policy to include the Rubrik service account.
    To do this, an Organization Admin must update the org-policy.yaml file with the following values.
    # org-policy.yaml
name: organizations/YOUR_ORG_ID/policies/iam.allowedPolicyMemberDomains
spec:
  rules:
    - values:
        allowedValues:
          - "<YOUR_CLOUD_IDENTITY_ID>"
          - "<RUBRIK_CLOUD_IDENTITY_ID>"

    Where YOUR_CLOUD_IDENTITY_ID is the Cloud Identity ID for your organization, and RUBRIK_CLOUD_IDENTITY_ID is the Cloud Identity ID Rubrik provides for the Rubrik organization.

  4. Apply the policy change.
    You can issue this command to apply the change to the policy:
    gcloud org-policies set-policy org-policy.yaml

Results

The Domain Restricted Sharing policy now includes the Rubrik service account.

What to do next

  • If your project uses VPC Service Controls, you must either add an ingress rule that permits the Rubrik service account or add the Rubrik GCP project to your access level so that Rubrik can access the VPC.

    Contact Rubrik Support for the specific project details needed for VPC-SC configuration.
