      • Introduction to Agent Cloud
        • Agent Cloud

          Agent Cloud detects risky actions caused on your data by autonomous AI agents, helps you find their root causes, and rewinds the actions to repair changes to the data and configurations without downtime.

        • How Agent Cloud works

          Agent Cloud splits its work between a control plane in RSC and a data plane that processes agent traffic, and it connects to your agents in one of four ways.

        • Key concepts for Agent Cloud

          Information about the core components of Agent Cloud and how these components work together to provide observability, security, and remediation for your AI infrastructure.

        • Common Agent Cloud terms

          Definitions of the terms used throughout the Agent Cloud documentation.

        • Early access features

          Early access features are Agent Cloud features that are available before general availability to organizations that opt in.

      • Get started with Agent Cloud

        To start using Agent Cloud, confirm the prerequisites, deploy a data plane, connect your agents, verify the setup, and then add policies.

      • Choose your data plane

        The Agent Cloud data plane runs as a SaaS deployment that Rubrik operates, or in your own AWS VPC or Azure VNet. Choose where it runs before you connect your AI providers and agents.

      • Connect your AI agents

        A connection links Agent Cloud to a source of agent activity, such as an enterprise AI platform, a gateway that your custom agents use, or the endpoint detection binary on employee devices.

      • Discover and observe

        Agent Cloud builds an inventory of the agents, tools, identities, models, and MCP servers in your environment, and records what each agent does, session by session.

      • Manage Agent Cloud policies

        Agent Cloud policies are the governance rules that define the acceptable behavior for your AI agents. Use them to detect risky activity and, on connections that support it, stop it.

      • Rewind AI agent changes with Agent Cloud

        Agent Rewind undoes the changes that an agent action made to your data by restoring the affected objects from Rubrik backups, without rolling back the entire workload. Rewind requires a complete Rubrik snapshot taken within seven days before the action.

      • Administer Agent Cloud

        Control who can see and manage Agent Cloud, review platform and user activity, understand who is responsible for each part of a deployment, and follow best practices for rollout and for building agents that are easier to govern.

Agent Cloud

Agent Cloud detects risky actions caused on your data by autonomous AI agents, helps you find their root causes, and rewinds the actions to repair changes to the data and configurations without downtime.

Autonomous AI agents can change or delete critical data, and teams often cannot see what an agent did or how to recover. Agent Cloud shows you what your agents are doing, detects risky actions, and rewinds the changes.

Visibility

See every agent, tool, and action in one place.

Agent inventory
discover the cloud, custom, and endpoint agents in your environment
Tools and MCP servers
see what each agent can access, and mark tools authorized or unauthorized
Explorer
view a map of the relationships between agents, tools, and applications
Sessions and actions
review the prompts, tool calls, and responses behind any action

Detection and control

Define acceptable agent behavior and respond when an agent steps outside it.

Policies and policy packs
use built-in or custom policies, or add curated packs for your industry
Flexible enforcement
monitor, block in real time, or pause for human approval
Alerts and ticketing
review violations and open Jira or ServiceNow tickets
Role-based access
control who can view sessions and who can manage policies

Recovery

Repair the effects of an agent action without disrupting everything else.

Root cause tracing
follow a change back to the agent, prompt, and tool that caused it
Single-action rewind
reverse one agent action without rolling back the whole workload
Rewind from any investigation page
start from Sessions, Actions, Alerts, or Insights
