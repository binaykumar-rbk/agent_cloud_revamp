      • Introduction to Agent Cloud
      • Get started with Agent Cloud

        To start using Agent Cloud, confirm the prerequisites, deploy a data plane, connect your agents, verify the setup, and then add policies.

      • Choose your data plane

        The Agent Cloud data plane runs as a SaaS deployment that Rubrik operates, or in your own AWS VPC or Azure VNet. Choose where it runs before you connect your AI providers and agents.

      • Connect your AI agents

        A connection links Agent Cloud to a source of agent activity, such as an enterprise AI platform, a gateway that your custom agents use, or the endpoint detection binary on employee devices.

      • Discover and observe

        Agent Cloud builds an inventory of the agents, tools, identities, models, and MCP servers in your environment, and records what each agent does, session by session.

        • AI inventory

          The inventory lists everything that Agent Cloud has discovered across your connections: agents, tools, identities, models, and MCP servers.

            View the list of AI agents monitored by Agent Cloud.

          • Viewing tool details

            View specific information about a tool, including its description, functional capabilities, and authorized agents.

          • Creating tool policy exceptions

            Edit a tool's configuration to create exceptions for policies.

          • Viewing the model inventory

            View information about models discovered by Agent Cloud.

          • Viewing MCP server details

            View specific information about an MCP server, including its configuration, the identities that use it, and the endpoints where it is installed.

        • Sessions and actions

          Agent Cloud records what your agents do as sessions, each with a timeline of prompts, responses, and tool calls, and as actions, the individual tool calls within them.

        • Dashboard and Explorer

          The Dashboard summarizes your agent environment and its open issues. The Explorer maps which agents can access which tools and applications.

        • Connections

          The Connections page displays all the connections configured on Agent Cloud. These include SaaS platform integrations, such as Microsoft Copilot Studio or AWS Bedrock, MDM connections for endpoint detection, and AI gateways (Rubrik-managed or plug-ins to third-party gateways such as LiteLLM).

      • Manage Agent Cloud policies

        Agent Cloud policies are the governance rules that define the acceptable behavior for your AI agents. Use them to detect risky activity and, on connections that support it, stop it.

      • Rewind AI agent changes with Agent Cloud

        Agent Rewind undoes the changes that an agent action made to your data by restoring the affected objects from Rubrik backups, without rolling back the entire workload. Rewind requires a complete Rubrik snapshot taken within seven days before the action.

      • Administer Agent Cloud

        Control who can see and manage Agent Cloud, review platform and user activity, understand who is responsible for each part of a deployment, and follow best practices for rollout and for building agents that are easier to govern.

AI inventory

The inventory lists everything that Agent Cloud has discovered across your connections: agents, tools, identities, models, and MCP servers.

Open the inventory from the Inventory menu. Which connections populate each inventory, and how much detail they provide, differs by connection. For example, API integrations report agents and tools, while endpoint detection also reports the MCP servers, skills, and plugins that Claude Code uses. For details, see the Agent Cloud support matrix.

Agents

The Agents inventory lists every discovered agent with its connection type, the date it was first discovered, its active violations and alerts, and its agent status. An agent's status is authorized or unauthorized. A system policy handles unauthorized agents, and whether Agent Cloud can block them depends on whether the connection supports blocking. The Discovered tab lists the agents that Agent Cloud has found. The page also shows how many agents are high risk and how many are inactive.

This table describes the filters available on the Agent Inventory page.
Filter Description
Applications Accessible Applications accessible by the AI agent.
Agent Risk Level of risk the action performed by the AI agent poses for your data or configuration.

The thumbtack icon pins AI agents to the top of the list. Pinned AI agents remain at the top of the list when you scroll.

This table describes the columns displayed on the Agent Inventory page.
Column Description
Name Name of the discovered AI agent.
Agent Risk Current risk level Agent Cloud assigns to the AI agent.
Active Violations Number of active violations for each AI agent.
Active Alerts Number of active alerts for each AI agent.
Apps Accessible Applications the AI agent can access.
Connection Type Connection from which the AI agents originate. For example, Microsoft Copilot Studio, LiteLLM, or Rubrik Gateway.
First Discovered Initial date and time Agent Cloud discovered the AI agent.

Select an agent to open its details. The following table describes the tabs.

This table describes the tabs on the agent details page.
Tab Description
Overview A summary of the agent and its connection.
Usage Token usage and estimated cost, broken down by model, with the top identities and sessions by spend, for connections that report usage.
Violations and Alerts The configuration violations and the alerts raised for the agent.
Actions and Sessions The agent's recorded actions and sessions.
Identities The people and service accounts that use the agent.
Capabilities The skills, MCP servers, and plugins that the agent uses. Endpoint detection reports these for Claude Code.

Tools

The Tools inventory lists the functions and APIs that agents can call. Each tool is classified by what it can do. A tool shows Pending Analysis while Agent Cloud is classifying it. Select a tool to see its overview, violations, alerts, sessions, and actions. To exclude a tool from a policy, add a policy exception. See Creating tool policy exceptions.

The following table describes the columns displayed on the Tools Inventory page.
Column Description
Tools Name of the tool Agent Cloud found running on the workload.
Capabilities The capabilities of the tool. Each tool can have one or more of the following capability types:
  • Read: Reading, retrieving, or viewing information
  • Update: Modifying existing resources or data
  • Create: Creating new resources, files, or data
  • Delete: Removing or destroying resources or data
  • Planning: Planning or preparing operations
  • Agent to Agent: Coordinating or orchestrating across agents

Tools may show "Pending Analysis" while classification is in progress.
Application Application that provides the tool.
Agents with Access Names of the agents with permission to access the tool.
Active Violations Number of active violations for this tool.
Active Alerts Number of active alerts associated with this tool.
Approval Status Whether the tool is Authorized or Unauthorized.
Last Used Last time this tool was invoked by an agent.
First Discovered Date and time Agent Cloud first discovered this tool.

Agent Cloud generates alerts when it detects a policy violation at runtime, whether triggered by a tool call, a user prompt, or an agent response. For the rules that determine which events trigger violations and alerts, see How policies work.

Identities

The Identities inventory lists the people and service accounts that use your agents. For each identity, it shows the source connection, the agents used, the hosts where the identity runs agents, and when it was last active. Select an identity to see its overview, violations, alerts, and actions. This shows everything one person or service account has done across all of their agents.

Models

The Models inventory lists the AI models discovered across all connections, including models used through native integrations such as Microsoft Copilot.

This table describes the columns displayed on the Models Inventory page.
Column Description
Name Name of the model specified by the provider.
Model Group Name of the group to which the model belongs.
First Discovered Date and time Agent Cloud discovered this model.
Approval Status Whether the model is Authorized or Unauthorized.

MCP servers

The Discovered tab of the MCP Servers inventory lists the MCP servers that endpoint detection found configured on devices. For each server, you can see its configuration and transport, the identities that have it configured, and the endpoints where it is installed. Agent Cloud collects MCP server configuration data through mobile device management (MDM).

Important:
Agent Cloud never collects secret values, such as environment variable values and HTTP header values. Agent Cloud collects only the names of environment variables and HTTP headers that an MCP server uses.
This table describes the columns displayed on the MCP Servers Inventory page.
Column Description
Name The name of the MCP server. The tooltip displays the server source, transport type, and connection configuration.
Agents with Access The AI agents that use this MCP server.
Identities with Access The number of distinct identities that have this MCP server configured.
Last Used The date and time Agent Cloud last detected this MCP server on an endpoint.
