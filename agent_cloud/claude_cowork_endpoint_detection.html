Claude Cowork

Agent Cloud captures and enforces policies on Claude Cowork sessions that run on the user's computer. Cowork sessions that run in Anthropic's cloud are not visible to endpoint detection.

Claude Cowork, Claude Desktop, and Claude Code

These products are related, which often causes confusion about what Agent Cloud covers.

  • Claude Desktop is the Claude desktop app. Plain chat conversations in it are discovery only: Agent Cloud reports that the app is installed and which MCP servers and extensions it has, but captures no conversations and enforces no policies on them.
  • Claude Cowork is the agent mode in the Claude Desktop app, which carries out multi-step tasks on the files of the user. It is available only through Claude Desktop. Cowork runs its sessions on Claude Code, which is why Agent Cloud can capture and enforce Cowork sessions that run on the device.
  • Claude Code is Anthropic coding agent. For its coverage, see Claude Code.

A user can therefore have both covered and uncovered activity in the same app: a Cowork task that runs on their computer is captured and enforced, while a chat conversation is not.

How Cowork runs on the computer of the user

When a Cowork session runs on the computer of the user, its agent loop, which handles the conversation and decides which tools to call, runs on the computer itself. Code that the agent runs is isolated in a virtual machine on the computer. Because the agent loop runs on the computer, Cowork reads the same system-wide Claude Code managed settings as Claude Code, and the hooks in them run on the computer.

This is what Agent Cloud relies on:

  • Enforcement: The Claude Code hooks that the endpoint detection binary installs in the managed settings also apply to Cowork. Before Cowork sends a prompt or runs a tool, it sends the item to Agent Cloud, which allows or blocks it. There is no separate setting for Cowork.
  • Session capture: Cowork keeps its session transcripts in the data of Claude Desktop app, not in the session directory of Claude Code, so the endpoint detection binary collects them from there. The transcripts use the same format as Claude Code sessions. On Windows, where the location depends on whether Claude Desktop was installed from the Microsoft Store or the standalone installer, and on whether it uses Anthropic or a third-party model provider, the binary checks every location.

Cowork sessions in the cloud

Cowork sessions that run in Anthropic cloud are not covered. The session runs on Anthropic servers and is saved to the Claude account of the user, so there is no transcript on the device and no device policy applies.

Important:
Where Cowork runs depends on the Claude plan of the user. Since October 6, 2026, new Cowork tasks on Claude Pro and Max plans run in the cloud, and there is no setting to run them on the computer instead. Team plans can run Cowork in the cloud, and Enterprise plans do so when an owner enables it. Cowork tasks that run in the cloud are not visible to endpoint detection. For the current behavior of each plan, see Anthropic's Claude Cowork architecture overview.

Deployment

Cowork coverage comes from the same deployment as Claude Code: deploy the endpoint detection binary with your MDM solution, and enable the Claude Code hooks. For details, see Claude Code.

Cowork reads only managed settings that are on the device. It does not read the server-managed settings of Claude, so delivering the hooks through the claude.ai admin console does not cover Cowork. If you use server-managed settings for Claude Code, keep the MDM-installed hooks on devices for Cowork.

Write policies for Cowork

The built-in tools of Cowork report names under the workspace MCP server, such as mcp__workspace__bash for running shell commands, rather than the Claude Code tool names, such as Bash. A policy that matches the tool name Bash does not match Cowork shell. When you scope a policy to specific tools, include the Cowork tool names, or use a natural-language policy, which evaluates what the tool does rather than its name.

Limitations

  • Cowork has no Linux desktop app, so endpoint detection covers Cowork on macOS and Windows only.
  • Agent Cloud cannot distinguish Cowork from Claude Code during enforcement. A policy scoped to Claude Code also applies to Cowork, and the reverse.
  • Cowork support for device managed settings is not documented by Anthropic, and the way Cowork runs has changed more than once. Use the steps in Verifying endpoint monitoring and enforcement to confirm that Cowork sessions are captured and enforced after you deploy.
