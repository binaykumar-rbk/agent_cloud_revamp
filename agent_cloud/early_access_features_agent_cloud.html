      • Introduction to Agent Cloud

        Describes what Agent Cloud does, how it works, the key concepts and terms, and the features that are available in early access.

        • Agent Cloud

          Agent Cloud with RSC gives you visibility into AI agents and their tools, controls over their actions, and the ability to rewind their mistakes. It enforces policies in real time, detects risky actions on your data and configurations, and reverts unauthorized changes without affecting other work.

        • How Agent Cloud works

          Agent Cloud splits its work between a control plane in RSC and a data plane that processes agent traffic, and it connects to your agents in one of four ways.

          Information about the core components of Agent Cloud and how these components work together to provide observability, security, and remediation for your AI infrastructure.

        • Common Agent Cloud terms

          Definitions of the terms used throughout the Agent Cloud documentation.

        • Early access features

      • Get started with Agent Cloud

        To start using Agent Cloud, confirm the prerequisites, deploy a data plane, connect your agents, verify the setup, and then add policies.

      • Deploy your data plane

        The Agent Cloud data plane runs as a SaaS deployment that Rubrik operates, or in your own AWS VPC or Azure VNet. Decide where it runs before you connect your AI providers and agents.

      • Connect your agents

        A connection links Agent Cloud to a source of agent activity, such as an enterprise AI platform, a gateway that your custom agents use, or the endpoint detection binary on employee devices.

      • Discover and observe

        Agent Cloud builds an inventory of the agents, tools, identities, models, and MCP servers in your environment, and records what each agent does, session by session.

      • Govern and control

        Agent Cloud policies are the governance rules that define the acceptable behavior for your AI agents. Use them to detect risky activity and, on connections that support it, stop it.

      • Rewind agent actions

        Agent Rewind undoes the changes that an agent action made to your data by restoring the affected objects from Rubrik backups, without rolling back the entire workload. You can start a rewind from the Sessions page, or from any page that displays the action or alert detail tray. Rewind requires a complete Rubrik snapshot taken within seven days before the action.

      • Administer Agent Cloud

        Control who can view and manage Agent Cloud, review platform and user activity, understand who is responsible for each part of a deployment, and follow best practices for rollout and for building agents that are easier to govern.

Early access features

Early access features are Agent Cloud features that are available before general availability to organizations that opt in.

Important:
Early access features are provided as a free trial. They may change before they become generally available, or may not be released for general availability.

Available early access features

  • MCP gateway: A governed endpoint between your agents and the MCP servers they use. For more information, see MCP gateway (Early access).
  • MCP access policies: Rules that control which identities can call which MCP servers and tools through the MCP gateway. For more information, see MCP access policies (Early access).
  • Codex endpoint support: Session capture and policy enforcement for Codex on managed endpoints. For more information, see Codex (Early access).
  • Pi Coding Agent endpoint support: Discovery of Pi Coding Agent on managed endpoints.
  • Session rewind: Undo the changes from several actions in one session at once. For more information, see Rewinding sessions from the Sessions page.

Opt in to early access

Opting in applies to your whole organization and enables all early access features, including features that are added later.

To opt in, in RSC, navigate to Settings > Agent Cloud > Preview. Click Opt in to preview, and then click Opt in to confirm.

Opt out of early access

On the same page, click Opt out of preview. Opting out turns off all early access features for your organization, and configurations that depend on them may be deactivated.
