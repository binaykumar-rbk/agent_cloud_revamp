          • Cost management for AWS VPC deployment

      • Connect your AI agents

        A connection links Agent Cloud to a source of agent activity, such as an enterprise AI platform, a gateway that your custom agents use, or the endpoint detection binary on employee devices.

      • Discover and observe

        Agent Cloud builds an inventory of the agents, tools, identities, models, and MCP servers in your environment, and records what each agent does, session by session.

      • Manage Agent Cloud policies

        Agent Cloud policies are the governance rules that define the acceptable behavior for your AI agents. Use them to detect risky activity and, on connections that support it, stop it.

      • Rewind AI agent changes with Agent Cloud

        Agent Rewind undoes the changes that an agent action made to your data by restoring the affected objects from Rubrik backups, without rolling back the entire workload. Rewind requires a complete Rubrik snapshot taken within seven days before the action.

      • Administer Agent Cloud

        Control who can see and manage Agent Cloud, review platform and user activity, understand who is responsible for each part of a deployment, and follow best practices for rollout and for building agents that are easier to govern.

AWS VPC deployment

Deploying AWS VPC in Agent Cloud involves provisioning the necessary infrastructure directly within your AWS account to establish a dedicated data plane.

Deploying AWS model gateways involves provisioning the necessary infrastructure directly within your AWS account. This configuration establishes a dedicated data plane within your AWS account, enabling Agent Cloud to monitor and govern your custom AI agents while ensuring sensitive data remains within your cloud boundary.

The model gateways process data locally within your virtual private cloud (VPC), but you perform all management and orchestration operations using Agent Cloud.

Key capabilities

  • Data sovereignty: The model gateway processes all sensitive agent traffic, such as prompts and responses, locally within your AWS VPC. This ensures that private data never leaves your controlled environment.
  • Hybrid management: You utilize a hybrid operational model where the data plane resides in your AWS account, but all orchestration, policy management, and reporting are handled through Agent Cloud.
  • Automated provisioning: You provide access to Agent Cloud so it can deploy the required resources, including Amazon EKS clusters and S3 buckets, using a Rubrik-provided AWS CloudFormation template, streamlining the setup process.

When to use AWS VPC

You can deploy this VPC when your custom AI agents and associated infrastructure are hosted in AWS. This minimizes latency by keeping the gateway close to your agents and leveraging your existing AWS security configurations.

Who does what

You run the Rubrik-provided CloudFormation template in your AWS account and send the output value to Rubrik. Rubrik Support then completes the deployment and tells you when the data plane is ready and Agent Cloud is visible in RSC.
