      • Get started with Agent Cloud

        To start using Agent Cloud, confirm the prerequisites, deploy a data plane, connect your agents, verify the setup, and then add policies.

      • Choose your data plane

        The Agent Cloud data plane runs as a SaaS deployment that Rubrik operates, or in your own AWS VPC or Azure VNet. Choose where it runs before you connect your AI providers and agents.

      • Connect your AI agents

        A connection links Agent Cloud to a source of agent activity, such as an enterprise AI platform, a gateway that your custom agents use, or the endpoint detection binary on employee devices.

        • Enterprise AI platforms
          • Microsoft Copilot Studio deployed in Agent Cloud

            Agent Cloud reads Microsoft Copilot Studio agents and conversation transcripts through the Dataverse API and, when you enable tool blocking, intercepts tool calls in real time through Copilot Studio's external threat detection integration.

          • Microsoft 365 Copilot deployed in Agent Cloud

            Agent Cloud reads Microsoft 365 Copilot interactions through the Microsoft Graph API to discover the users and agents that use Copilot and to record their sessions.

          • Microsoft Foundry (new) deployed in Agent Cloud

            Agent Cloud reads Microsoft Foundry (new) agent activity from the Azure Application Insights resource linked to a Foundry project, through a service principal that you grant read access.

          • Microsoft Foundry (classic) deployed in Agent Cloud

            Agent Cloud reads Microsoft Foundry (classic) agent activity from the Azure Application Insights resource linked to a Foundry project, through a service principal that you grant read access. Only instrumented agents are observed.

            • Deploying ChatGPT Enterprise in Agent Cloud

              Deploy ChatGPT Enterprise in Agent Cloud to enable agent discovery, conversation ingestion, and tool-call monitoring for a ChatGPT Enterprise workspace.

          • Claude Enterprise deployed in Agent Cloud

            Agent Cloud reads Claude Enterprise activity after the fact through Anthropic's Compliance API, using a read-only Compliance API key.

          • Google Cloud Gemini Enterprise in Agent Cloud

            Agent Cloud uses a Google Cloud service account that you create to discover agents and read their conversation sessions in a Google Cloud project, covering both Gemini Enterprise and Gemini Enterprise Agent Platform (Vertex AI Agent Engine).

          • AWS Bedrock Agents deployed in Agent Cloud

            Agent Cloud reads Amazon Bedrock model invocation logs from Amazon CloudWatch Logs or an Amazon S3 bucket, through an IAM role in your AWS account that Agent Cloud assumes.

          • Amazon Bedrock AgentCore deployed in Agent Cloud

            Agent Cloud reads the OpenTelemetry runtime logs that Amazon Bedrock AgentCore writes to Amazon CloudWatch, through an IAM role in your AWS account that Agent Cloud assumes.

        • Custom agents

          Custom agents that you build connect to Agent Cloud through the Rubrik AI gateway, through your existing LiteLLM proxy, or by exporting OpenTelemetry traces.

        • Endpoint detection

          The Rubrik endpoint detection binary runs on employee devices to discover the AI agents installed there and the identities that use them, and, for supported agents, to capture their sessions and enforce policies in real time.

      • Discover and observe

        Agent Cloud builds an inventory of the agents, tools, identities, models, and MCP servers in your environment, and records what each agent does, session by session.

      • Manage Agent Cloud policies

        Agent Cloud policies are the governance rules that define the acceptable behavior for your AI agents. Use them to detect risky activity and, on connections that support it, stop it.

      • Rewind AI agent changes with Agent Cloud

        Agent Rewind undoes the changes that an agent action made to your data by restoring the affected objects from Rubrik backups, without rolling back the entire workload. Rewind requires a complete Rubrik snapshot taken within seven days before the action.

      • Administer Agent Cloud

        Control who can see and manage Agent Cloud, review platform and user activity, understand who is responsible for each part of a deployment, and follow best practices for rollout and for building agents that are easier to govern.

ChatGPT Enterprise coverage and requirements for Agent Cloud

Deploying ChatGPT Enterprise on Agent Cloud requires a ChatGPT Enterprise workspace with Compliance API access, as well as administrative roles in both OpenAI and Agent Cloud. Administrators should also review the integration's coverage and limitations before deploying ChatGPT Enterprise on Agent Cloud.

Prerequisites

Deploying ChatGPT Enterprise on Agent Cloud requires:

  • An RSC role with the Manage Agent Operations privilege so that an administrator can add the connection in Agent Cloud.
  • A ChatGPT Enterprise plan. OpenAI offers the Compliance API only on the Enterprise plan.
  • The Owner role on the ChatGPT Enterprise workspace, which is required to create an Admin API key in the ChatGPT Enterprise admin console.
  • Compliance API access provisioned by OpenAI for the Admin API key. The Admin API key alone does not grant access to the Compliance API. OpenAI provisions this access manually per key, on request.

AI agent coverage

Agent Cloud supports ChatGPT Enterprise within the behaviors and limits described below.

  • Near-real-time, not real-time: ChatGPT Enterprise does not push data to Agent Cloud. Instead, Agent Cloud pulls activity data, which appears within approximately 10 minutes of the activity taking place in ChatGPT Enterprise. Very recent tool-call data may take an extra cycle to appear alongside its conversation.
  • One connection per workspace: Agent Cloud rejects a second connection for the same Workspace ID to avoid double ingestion. Agent Cloud enables an administrator to re-add a previously deleted workspace.
  • Initial lookback: The first check after a connection is created looks back 4 hours. Agent Cloud does not ingest older activity. When you delete and re-add a connection—for example, to rotate the Admin API key—Agent Cloud does not backfill activity older than 4 hours from the re-add.
  • Forked or regenerated conversations appear linear: When you edit or regenerate an earlier message, Agent Cloud shows the resulting branches as a single linear thread, because OpenAI does not expose branch information in compliance data.
  • Text content only: Agent Cloud does not ingest image generation, voice mode, file uploads, or code-interpreter outputs.
  • Identity correlation: Agent Cloud attributes each session to a user by their ChatGPT Enterprise email. Agent Cloud does not link ChatGPT Enterprise users to other identity platforms.
  • Agent discovery scope: Agent Cloud discovers only the custom GPTs that OpenAI exposes for the workspace through the Compliance API. Custom GPTs not surfaced through the Compliance API do not appear in the agent inventory.
