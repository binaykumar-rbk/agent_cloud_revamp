        • Agent Cloud support matrix

          Agent Cloud supports multiple platform integrations, each with varying capabilities for AI agent discovery, session activity monitoring, policy enforcement, configuration violations, monitoring alerts, blocking, and ask enforcement.

        • Builder platforms

          Describes how to connect platforms where you build and host your own agents, such as Microsoft Copilot Studio, Google Cloud Gemini Enterprise, and Amazon Bedrock.

        • Enterprise apps

          Describes how to connect vendor-managed AI applications that your employees use: ChatGPT Enterprise, Claude Enterprise, and Microsoft 365 Copilot.

        • AI gateways

          Custom agents that you build connect to Agent Cloud through the Rubrik AI gateway or through your existing LiteLLM proxy. Agents that export OpenTelemetry traces connect under Observability.

        • Observability

          Describes how to send OpenTelemetry traces from your agent frameworks to Agent Cloud.

        • Endpoint detection

          The Rubrik endpoint detection binary runs on employee devices to discover the AI agents installed there and the identities that use them, and, for supported agents, to capture their sessions and enforce policies in real time.

      • Discover and observe

        Agent Cloud builds an inventory of the agents, tools, identities, models, and MCP servers in your environment, and records what each agent does, session by session.

      • Govern and control

        Agent Cloud policies are the governance rules that define the acceptable behavior for your AI agents. Use them to detect risky activity and, on connections that support it, stop it.

      • Rewind agent actions

        Agent Rewind undoes the changes that an agent action made to your data by restoring the affected objects from Rubrik backups, without rolling back the entire workload. You can start a rewind from the Sessions page, or from any page that displays the action or alert detail tray. Rewind requires a complete Rubrik snapshot taken within seven days before the action.

Connect your agents

A connection links Agent Cloud to a source of agent activity, such as an enterprise AI platform, a gateway that your custom agents use, or the endpoint detection binary on employee devices.

Important:
Connections differ in what they discover, what session activity they capture, and whether they can block actions in real time. Most connections cannot block, and block policies on those connections behave like monitor policies. For what each connection supports, see Agent Cloud support matrix. For help choosing between connection types, see Choose how to connect your agents.

Connection categories

A connection belongs to one of the following categories. In the Agent Cloud user interface, connections are grouped under Connectors.

The following table describes the connection categories, how each category reads agent activity, and where each appears in the user interface.
Category What it covers Shown in the UI under
Builder platforms Platforms where you build and host your own agents. Agent Cloud reads agents and sessions through each platform APIs: Microsoft Copilot Studio, Microsoft Foundry, Google Cloud Gemini Enterprise, Amazon Bedrock Agents, and Amazon Bedrock AgentCore. Builder Platforms
Enterprise apps Vendor-managed AI applications that your employees use. Agent Cloud reads agents and sessions through APIs of each application: ChatGPT Enterprise, Claude Enterprise, and Microsoft 365 Copilot. Enterprise Apps
AI gateways Agents that you build send their model traffic through the Rubrik AI gateway or through your LiteLLM proxy, so that Agent Cloud can record and, where supported, block it in real time. AI Gateways
Observability Agents built on a framework that emits OpenTelemetry traces send the traces to Agent Cloud. Traces are exported after the fact, so this connection cannot block. Observability
Endpoint detection The Rubrik endpoint detection binary, deployed through your Mobile Device Management (MDM) solution or installed manually, discovers coding and desktop agents on employee devices and, for supported agents, captures their sessions. Endpoint Detection

A gateway is required only for custom agents that you want to block in real time. Enterprise AI platform connections, such as Microsoft Copilot Studio, connect directly to Agent Cloud and do not require a gateway. For the trade-offs between connection types, see Choose how to connect your agents.

View connections

To view your connections, in Agent Cloud, click Connectors. Select a category to view its connections. Depending on the connection type, the list shows the connection name, the number of agents discovered, the time of the last sync, whether tool blocking is configured, who added the connection and when, and type-specific details such as the tenant ID, environment URL, or project.

Delete a connection

To delete a connection, click Connectors, click the More icon for the connection, select Delete, and confirm.

Attention:
Deleting a connection stops Agent Cloud from collecting activity through it, and removes its credentials and the resources that Agent Cloud created for it, such as API keys. This action cannot be undone.

Manage gateway API keys

Custom agents authenticate to the Rubrik AI gateway with gateway API keys. To view, generate, or delete them, see Manage gateway API keys.
