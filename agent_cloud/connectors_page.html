        To start using Agent Cloud, confirm the prerequisites, deploy a data plane, connect your agents, verify the setup, and then add policies.

      • Deploy your data plane

        The Agent Cloud data plane runs as a SaaS deployment that Rubrik operates, or in your own AWS VPC or Azure VNet. Decide where it runs before you connect your AI providers and agents.

      • Connect your agents

        A connection links Agent Cloud to a source of agent activity, such as an enterprise AI platform, a gateway that your custom agents use, or the endpoint detection binary on employee devices.

        Agent Cloud builds an inventory of the agents, tools, identities, models, and MCP servers in your environment, and records what each agent does, session by session.

        • AI inventory

          The inventory lists everything that Agent Cloud has discovered across your connections: agents, tools, identities, models, and MCP servers.

        • Sessions and actions

          Agent Cloud records what your agents do as sessions, each with a timeline of prompts, responses, and tool calls, and as actions, the individual tool calls within them.

        • Dashboard and Explorer

          The Dashboard summarizes your agent environment and its open issues. The Explorer maps which agents can access which tools and applications.

      • Govern and control

        Agent Cloud policies are the governance rules that define the acceptable behavior for your AI agents. Use them to detect risky activity and, on connections that support it, stop it.

      • Rewind agent actions

        Agent Rewind undoes the changes that an agent action made to your data by restoring the affected objects from Rubrik backups, without rolling back the entire workload. You can start a rewind from the Sessions page, or from any page that displays the action or alert detail tray. Rewind requires a complete Rubrik snapshot taken within seven days before the action.

Connections

The Connections page displays all the connections configured on Agent Cloud. These include SaaS platform integrations, such as Microsoft Copilot Studio or AWS Bedrock, MDM connections for endpoint detection, and AI gateways (Rubrik-managed or plug-ins to third-party gateways such as LiteLLM).

View and delete connections

Connections differ in what they discover, what session activity they capture, and whether they can block actions in real time. For what each connection supports, see Agent Cloud support matrix.

To view your connections, click Connectors and select a category. Depending on the connection type, the list shows the connection name, the number of agents discovered, the time of the last sync, whether tool blocking is configured, who added the connection and when, and type-specific details such as the tenant ID, environment URL, or project. For more information, see Viewing the connected model gateways.

To delete a connection, click Connectors, click the More icon for the connection, select Delete, and confirm. Deleting a connection stops Agent Cloud from collecting activity through it, and removes its credentials and the resources that Agent Cloud created for it, such as API keys. This action cannot be undone. For more information, see Deleting the connected model gateways.

Each connection type has its own authentication method. For example, Rubrik-managed gateways use API keys, while other connector types may use different credentials. To view, generate, or delete gateway API keys, see Manage gateway API keys.

Connections inventory

The Connectors page displays all connections to Agent Cloud. Use the navigation on the left to view all connections or the connections in one category.

The following table describes the categories in the Connectors navigation and the connections that each one lists.

Browser Apps None documented yet Displays the browser app connections.
Enterprise Apps ChatGPT Enterprise, Claude Enterprise, Microsoft Copilot 365 Displays the vendor-managed AI applications that your employees use.
AI Gateways LiteLLM, MCP Gateways, Rubrik-Managed Gateway Displays the gateways that your custom agents send model traffic through.
Observability OpenTelemetry Displays the connections that send observability data to Agent Cloud, such as OpenTelemetry traces.

Viewing the connected model gateways

View the model gateways connected to Agent Cloud.

Procedure

  1. Log in to RSC.
  2. Click and select Agent Cloud.
    The Agent Cloud page appears.
  3. Click Connectors.
    Agent Cloud displays the Connections Inventory page with a list of connected AI models. The Connections Inventory page includes information about model gateways and native integrations such as Microsoft Copilot.
  4. Select the row for the connected AI models to view.
    Agent Cloud displays the Connected Models page.
  5. Optional: From Connected Models, select the model gateway types displayed.
    • All Providers
    • OpenAI
    • Anthropic
    Agent Cloud filters the list of AI gateway models.

Results

You have viewed the AI models connected to Agent Cloud.

Deleting the connected model gateways

Delete an AI model gateway connected to Agent Cloud and clean up associated resources, including API keys, webhooks, and log processors.

About this task

When a model gateway is no longer needed, you can delete it from the Connectors page. Deleting a model gateway removes all associated resources, including API keys and log processors.
Warning:
This action cannot be undone.

Procedure

  1. Log in to RSC.
  2. Click and select Agent Cloud.
    The Agent Cloud page appears.
  3. Click Connectors.
    Agent Cloud displays the Connections Inventory page with a list of connected AI model gateways. The Connections Inventory page includes information about model gateways and native integrations such as Microsoft Copilot.
  4. Select then click Delete for the model gateway to delete.

Results

Agent Cloud deletes the model gateway. The gateway and its associated API keys, webhooks, and log processors are permanently removed.
