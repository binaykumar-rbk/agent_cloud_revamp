          • Microsoft 365 Copilot deployed in Agent Cloud

            Agent Cloud reads Microsoft 365 Copilot interactions through the Microsoft Graph API to discover the users and agents that use Copilot and to record their sessions.

          • Microsoft Foundry (new) deployed in Agent Cloud

            Agent Cloud reads Microsoft Foundry (new) agent activity from the Azure Application Insights resource linked to a Foundry project, through a service principal that you grant read access.

          • Microsoft Foundry (classic) deployed in Agent Cloud

            Agent Cloud reads Microsoft Foundry (classic) agent activity from the Azure Application Insights resource linked to a Foundry project, through a service principal that you grant read access. Only instrumented agents are observed.

          • ChatGPT Enterprise deployed in Agent Cloud

            Agent Cloud polls OpenAI's Compliance API every 10 minutes to discover custom GPTs and ingest conversations and tool calls from a ChatGPT Enterprise workspace.

          • Claude Enterprise deployed in Agent Cloud

            Agent Cloud reads Claude Enterprise activity after the fact through Anthropic's Compliance API, using a read-only Compliance API key.

          • Google Cloud Gemini Enterprise in Agent Cloud

            Agent Cloud uses a Google Cloud service account that you create to discover agents and read their conversation sessions in a Google Cloud project, covering both Gemini Enterprise and Gemini Enterprise Agent Platform (Vertex AI Agent Engine).

          • AWS Bedrock Agents deployed in Agent Cloud

            Agent Cloud reads Amazon Bedrock model invocation logs from Amazon CloudWatch Logs or an Amazon S3 bucket, through an IAM role in your AWS account that Agent Cloud assumes.

          • Amazon Bedrock AgentCore deployed in Agent Cloud

            Agent Cloud reads the OpenTelemetry runtime logs that Amazon Bedrock AgentCore writes to Amazon CloudWatch, through an IAM role in your AWS account that Agent Cloud assumes.

        • Custom agents

          Custom agents that you build connect to Agent Cloud through the Rubrik AI gateway, through your existing LiteLLM proxy, or by exporting OpenTelemetry traces.

        • Endpoint detection

          The Rubrik endpoint detection binary runs on employee devices to discover the AI agents installed there and the identities that use them, and, for supported agents, to capture their sessions and enforce policies in real time.

      • Discover and observe

      • Manage Agent Cloud policies

      • Rewind AI agent changes with Agent Cloud

Deploying Microsoft Copilot Studio to Agent Cloud

Deploy Microsoft Copilot Studio to Agent Cloud to enable agent discovery, activity logging, and real-time tool blocking.

Before you begin

Deploying Microsoft Copilot Studio to Agent Cloud requires:
  • Adding the RSC application user.
  • Registering the Azure Enterprise App in the Microsoft Threat Detection interface to enable real-time tool blocking.
  • Accessing the environment URL and tenant ID for the target Microsoft Copilot Studio environment.
  • Having Power Platform admin permissions to create application users and manage security roles.
  • Having Microsoft Entra ID global administrator permissions to grant admin consent for threat detection.

About this task

This task has five stages: Record your Copilot Studio environment details, Grant consent and start the connection wizard, Create the security role, Create the application user, and Finish the connection in the wizard.

Onboarding a Microsoft Copilot Studio environment to Agent Cloud provides comprehensive visibility into AI agent activities and enables Agent Cloud to intercept and block activities that violate defined policies in real time.

Attention:
The onboarding process requires you to copy information from the Microsoft Power Platform Admin Center (MPPAC) environment and paste it into the Agent Cloud environment. Run both UIs simultaneously to make it easier to copy the data between them.

Procedure

Stage 1: Record your Copilot Studio environment details
  1. Open MPPAC and from the gear icon, select Session details.
  2. In the window MPPAC displays, record the Tenant ID and close the window.
  3. Navigate to Manage > Environments.
    The Environments page appears.
  4. From the Environment column, select the name of the Copilot Studio environment in which your agents are deployed.
    The environment details page appears.
  5. From the environment details page, record the Microsoft Copilot Studio environment details.
    This table describes the details to record in a location you can access later.
    DetailDescription
    Environment URL URL to the Microsoft Copilot Studio environment.
    Environment Name Name of the environment where your agents are deployed.
    When you are done recording the Microsoft Copilot Studio environment details, leave this window open so you can perform more tasks.
Stage 2: Grant consent and start the connection wizard
  1. Use a new window to grant admin consent for the Azure management account for Agent Cloud.
    You can grant admin consent for the Azure management account by opening this URL and accepting the admin consent: https://login.microsoftonline.com/common/adminconsent?client_id=f1361b79-e5b0-4dc4-b715-f3610d14e30d&redirect_uri=https://localhost:3000
    Attention:
    Granting admin consent requires that you log in with an account that has admin privileges for the Entra ID tenant with which the Copilot Studio environment is associated.
  2. In a new browser window, log in to RSC.
  3. Click and select Agent Cloud.
    The Agent Cloud page appears.
  4. Click Inventory > Connections.
  5. Click Cloud Platforms > Microsoft Copilot Studio.
  6. Click Add a Connection.
    Agent Cloud displays the Connect to Microsoft Copilot Studio wizard.
  7. In Connect Environment, enter the Environment URL, Tenant ID, and Name you recorded earlier.
    You can enter any name for the environment name, but Rubrik recommends that you enter the same name you recorded earlier.
  8. Click Next.
  9. From Use this App ID for the Application User, copy and record the App ID in a location you can access later.
    When you are done recording the App ID, leave this window open so you can perform more tasks.
Stage 3: Create the security role
  1. In MPPAC, from the Copilot Studio environment details page, select Settings > Users + Permissions > Security Roles.
  2. Click + New role.
    The Create New Role dialog opens.
  3. Enter the details for this new role.
    FieldDescription
    Role Name Enter a name for the role, such as Rubrik Agent Cloud Reader.
    Business Unit Select a business unit.
    Description Enter a description for the role. For example, This role is used by Rubrik Agent Cloud to read information about Copilot agents.
    Applies to Enter the system to which this role applies. For example, Rubrik Agent Cloud
  4. In Summary of Core Table Privileges, enter a description of the privileges required for this role. For example, Organizational read access to bots (agents), their transcripts and users.
  5. Verify that Include App Opener privileges for running Model-Driven apps is selected.
  6. Click Save.
    A screen opens for setting permissions.
  7. Verify that each of the tables below has Read permissions set to Organization.
    Table Privilege name Read permission
    Copilot bot Organization
    Agent component botcomponent Organization
    Agent component collection botcomponentcollection Organization
    Conversation Transcript conversationtranscript Organization
    User systemuser Organization
  8. Click Save.
Stage 4: Create the application user
  1. In MPPAC, from the Microsoft Copilot Studio environment details page, select Settings > Users + Permissions > Application Users.
  2. Click + New app user.
    The Create a new app user dialog appears.
  3. Click + Add an app.
    The Add an app from Microsoft Entra ID dialog box appears.
  4. In Search by App Name or the full App ID, enter the App ID you recorded earlier.
  5. Click Rubrik Agent Cloud and then Add.
  6. In Create a new app user, enter the application user details and click Create.
    FieldAction
    Business Unit Select your root business unit.
    Security Roles Select the role you created earlier. For example, Rubrik Agent Cloud Reader.
  7. Click Create.
Stage 5: Finish the connection in the wizard
  1. Switch to the Agent Cloud window where the Connect to Microsoft Copilot Studio wizard is still open.
  2. Click I have created the Application User with the required roles, and then click Next.
    The Enable Tool Blocking page appears.
  3. To finish the deployment without enabling tool blocking, click Done.
    To enable tool blocking, continue with the deployment.

Results

You have connected the Microsoft Copilot Studio environment to Agent Cloud.

What to do next

  • To enable tool blocking, continue the MPPAC configuration in Enabling tool blocking on Agent Cloud.
  • Repeat this task for any additional Microsoft Copilot Studio environments that need to be managed by Agent Cloud.
