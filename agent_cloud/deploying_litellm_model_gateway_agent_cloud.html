            Model gateways are the fundamental infrastructure components that enable Agent Cloud to govern, monitor, and secure your AI agent interactions.

          • Manage gateway API keys

            Agent Cloud uses API keys to authenticate AI agents and a dual-key architecture — upstream keys and model gateway keys — to secure agent traffic.

          • OpenTelemetry

            An OpenTelemetry connection monitors AI agent activity from your existing agent frameworks and displays it as sessions in Agent Cloud.

        • Endpoint detection

          The Rubrik endpoint detection binary runs on employee devices to discover the AI agents installed there and the identities that use them, and, for supported agents, to capture their sessions and enforce policies in real time.

      • Discover and observe

        Agent Cloud builds an inventory of the agents, tools, identities, models, and MCP servers in your environment, and records what each agent does, session by session.

      • Manage Agent Cloud policies

        Agent Cloud policies are the governance rules that define the acceptable behavior for your AI agents. Use them to detect risky activity and, on connections that support it, stop it.

      • Rewind AI agent changes with Agent Cloud

        Agent Rewind undoes the changes that an agent action made to your data by restoring the affected objects from Rubrik backups, without rolling back the entire workload. Rewind requires a complete Rubrik snapshot taken within seven days before the action.

      • Administer Agent Cloud

        Control who can see and manage Agent Cloud, review platform and user activity, understand who is responsible for each part of a deployment, and follow best practices for rollout and for building agents that are easier to govern.

Connecting a LiteLLM proxy

Connect an existing LiteLLM proxy to Agent Cloud to enable real-time monitoring and governance of custom AI agents.

About this task

Deploying LiteLLM as a model gateway allows Agent Cloud to intercept agent requests, ingest activity logs, and apply governance policies before actions are executed.

Procedure

  1. Log in to RSC.
  2. Click and select Agent Cloud.
    The Agent Cloud page appears.
  3. Select Inventory > Connections.
  4. Click AI Gateways > LiteLLM.
  5. Click Add a Connection.
    Agent Cloud displays the Connect LiteLLM Plugin wizard.
  6. In Connection Name, enter the name of the connection.
    This is the connection from LiteLLM to Agent Cloud.
  7. Click Generate Credentials.
    You can use these to authenticate your connection from LiteLLM to Agent Cloud.
    The Connect LiteLLM Plugin wizard generates a Webhook URL and an API key.
    Attention:
    Save the Webhook URL and API key values to a safe location. Agent Cloud does not display them again after this.
  8. Click View Credentials to view the Webhook URL and API key values as rubrik_callback settings.
    Add the callback to your litellm_config.yaml file:
    general_settings:
  callbacks: ["rubrik_callback"]
rubrik_callback:
  webhook_url: "webhook_url"
  api_key: "api_key"
    When you run LiteLLM locally, set the RUBRIK_WEBHOOK_URL and RUBRIK_API_KEY environment variables instead. Restart or redeploy the LiteLLM proxy to apply the configuration.
  9. Click Done to exit the Configuration Guide window.
  10. Click Finish.

Results

You have generated the credentials to connect LiteLLM model gateway to Agent Cloud, and this connection is listed on the Connections Inventory page.

What to do next

Use these credentials to connect LiteLLM to Agent Cloud. Once this connection is complete, the Connections Inventory page will list logs from this model gateway.
